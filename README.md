# Ciao, sono Davide Raimondi! 👋

### 👨‍💻 Frontend Developer | Mobile App Creator | Indie Web Game Dev

Benvenuto nel mio profilo GitHub. Mi occupo di sviluppo web frontend, creazione di applicazioni mobile e progettazione di web game ultraleggeri. Mi specializzo nella realizzazione di web app interattive e giochi arcade (HTML5, CSS3 e JavaScript) ad alte prestazioni, con rendering vettoriale e su Canvas 2D, sintesi sonora tramite Web Audio API e interfacce mobile-first progettate per garantire fluidità e reattività su qualsiasi dispositivo.

---

### 🚀 Aree di Focus

- 🎮 **Web & Mobile Games**: Sviluppo di giochi arcade, action, runner e puzzle in HTML/CSS/JS, ottimizzati per controlli touch e viewport verticali.
- 📱 **Mobile & Web Apps**: Creazione di applicazioni utility, gestionali ed educative con interfacce moderne, intuitive e veloci.
- ⚡ **Performance & Audio/Video Web**: Codice puro in Vanilla JavaScript, animazioni vettoriali/Canvas e sintesi sonora generata in tempo reale.
